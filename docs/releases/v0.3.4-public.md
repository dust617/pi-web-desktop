# v0.3.4-public

> 本版本为 v0.3.3-public 的发布流程加固版本，从独立的公开发布树构建；运行态、会话数据、遥测、日志、个人配置、基础设施报告和私有运维文档均不包含在公开提交或 Release 中。

## 脱敏与发布流程加固

- **发布扫描器加固**：降低误报率，支持大体积已跟踪 blob 的快照扫描，强化脱敏快照的发布前检查；确保发布流程对生成式 Pi Web chunk 与测试夹具不误判，同时不放过真实敏感值。
- **防止隐式发布桌面构建产物**：禁用推断式 electron-builder 发布，显式阻断桌面 artifact 的隐式上传；打包命令统一使用 `--publish never`，构建配置设为 `publish: null`。
- **排除 Next.js 构建产物**：发布快照排除 `resources/pi-web/.next/` 构建产物目录（体积大、含本机绝对路径、易变），与公开仓库只保留源码的策略一致。
- **保留智能路由扩展源码**：确保 model-router-auto 扩展源码完整进入公开快照，不被误排除。
- **隧道崩溃循环测试**：补充等待隧道崩溃循环状态的测试，覆盖移动端 BFF 隧道恢复的边界情况。

## 智能路由子项目

继续随主仓库发布 [`packages/model-router-auto`](../../packages/model-router-auto)：面向 Pi Coding Agent 的模型路由与编排扩展。

- 在推理边界按任务阶段、上下文窗口、安全约束、停滞信号和模型黏性选择模型。
- 提供 fail-closed 权限门、日志脱敏、遥测轮转、监督提示和隔离审查沙箱。
- 以 `orchestrator.example.json` 提供匿名配置模板；不随仓库提供任何实际 Provider、模型、认证或使用记录。

## Pi Web 兼容性与安全状态

- 内置运行时的包元数据仍为 `@agegr/pi-web` **0.8.1** 与 Pi **0.82.1**；本版本没有将其伪装成完整的上游 0.8.3 或 0.8.9 升级。
- 本地安全/兼容性修复包括：模型发现不会把保存的认证信息转发到请求指定的目标；Windows 短路径下的项目可信判定已规范化；移动端 BFF 的写操作保持 fail-closed Origin 校验。
- 截止本次发布切点，未能核验到上游公开的 `v0.8.9` Release 或其安全公告；因此本 Release **不声明**已适配或合入 0.8.9。

## 验证

在生成快照前，完整本地源树执行 memory 治理检查；该检查依赖的本地规划/记忆文件刻意不在公开树中。公开发布树在推送与打 tag 前执行：脱敏快照扫描、独立敏感模式扫描、源代码 whitespace 检查、根项目构建、Pi Web 与移动端回归、桌面打包及一致性检查、智能路由类型检查/测试和隧道测试。打包命令显式使用 `--publish never`，且构建配置设为 `publish: null`；两者共同确保构建过程不会隐式上传构建产物。
