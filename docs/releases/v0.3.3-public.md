# v0.3.3-public

## 公开发布与脱敏

- 本版本从独立的公开发布树构建；运行态、会话数据、遥测、日志、个人配置、基础设施报告和私有运维文档均不包含在公开提交或 Release 中。
- 智能路由仅提供源码、测试和无个人信息的示例配置；真实模型映射、认证信息、会话状态与遥测保持在本地且被 Git 忽略。

## 新增：智能路由子项目

新增 [`packages/model-router-auto`](../../packages/model-router-auto)：面向 Pi Coding Agent 的模型路由与编排扩展。

- 在推理边界按任务阶段、上下文窗口、安全约束、停滞信号和模型黏性选择模型。
- 提供 fail-closed 权限门、日志脱敏、遥测轮转、监督提示和隔离审查沙箱。
- 以 `orchestrator.example.json` 提供匿名配置模板；不会随仓库提供任何实际 Provider、模型、认证或使用记录。

## Pi Web 兼容性与安全状态

- 内置运行时的包元数据仍为 `@agegr/pi-web` **0.8.1** 与 Pi **0.82.1**；本版本没有将其伪装成完整的上游 0.8.3 或 0.8.9 升级。
- 本地安全/兼容性修复包括：模型发现不会把保存的认证信息转发到请求指定的目标；Windows 短路径下的项目可信判定已规范化；移动端 BFF 的写操作保持 fail-closed Origin 校验。这些修复来自本地的“0.8.3 部分适配”工作，但本公开快照没有附带可审计的上游 0.8.3 提交映射，因此**不将其标注为完整或官方 0.8.3 升级**。
- 截止本次发布切点，未能核验到上游公开的 `v0.8.9` Release 或其安全公告；因此本 Release **不声明**已适配或合入 0.8.9。后续上游可用时将单独审计、测试并发布。

## 验证

在生成快照前，完整本地源树执行 memory 治理检查；该检查依赖的本地规划/记忆文件刻意不在公开树中。公开发布树在推送与打 tag 前执行：脱敏快照扫描、独立敏感模式扫描、源代码 whitespace 检查、根项目构建、Pi Web 与移动端回归、桌面打包及一致性检查、智能路由类型检查/测试和隧道测试。打包命令显式使用 `--publish never`，且构建配置设为 `publish: null`；两者共同确保构建过程不会隐式上传构建产物。
