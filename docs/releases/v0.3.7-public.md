- 内置运行时包升级至 `@agegr/pi-web` **0.8.7**（Pi Coding Agent 升级至 **0.84.0**）。
- 上游 v0.8.7 主要变更：
  - **传输稳定性修复**：修复 openai-codex WebSocket 会话共享问题（#7364），这是此前 GPT 频繁 `fetch failed`/`terminated` 的根因；同时升级 undici 8.9.0、加大连接超时（#7435）、瞬时失败自动重试（#7632）。这些是通用传输层修复，同样惠及 aliyun 等 provider。

  - 修复对话尾部跟随、提示词顶部定位、滚动锚点保留
- 下游适配（重建 `session-ui-adapters.patch` 对齐 v0.8.7）：

  - **恢复 `empty-abort-retry.ts` + `session-diagnostics.ts` + rpc-manager 插桩**（曾在 0.8.7 stage 时静默丢失，现登记进 patch manifest，未来升级不再丢）

## 本次适配机制改进

- **重新生成 `pi-web-ui-adapters.patch` 为最小 hunk**：此前一次重生成误用了整文件替换（`diff -ruN`），会让未来升级极脆弱；现改用 `git diff --no-index`（Myers）重生成，SessionSidebar 从整文件缩回 ~220 行增量。
- **AGENTS.md 增加 pi-web 适配硬约束**：任何对 `resources/pi-web/` 源码的改动必须登记进 `pi-web-patch-manifest.json`，否则下次 stage 会丢失（empty-abort-retry 即为实例）。
- **放宽 GPT 临时缓解**：0.84 已修复传输根因，移除 GPT 并发数/thinking 等级/会话长度的临时限制，保留 context hygiene 好习惯。
- **git 不再跟踪 `resources/pi-web/.next/`** 构建产物（gitignore），避免每次构建产生大量 diff。
