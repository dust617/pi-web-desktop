# v0.3.5-public

> 本版本在 v0.3.4-public 基础上将内置 Pi Web 运行时升级至 0.8.5，并加固自动换包的版本选择；从独立的公开发布树构建，运行态、会话数据、遥测、日志、个人配置、基础设施报告和私有运维文档均不包含在公开提交或 Release 中。

## Pi Web 运行时升级

- 内置运行时包元数据从 `@agegr/pi-web` **0.8.1** 升级至 **0.8.5**，Pi Coding Agent 从 0.82.1 升级至 **0.83.0**（pi-ai 同步至 0.83.0）。
- 完成 0.8.1 → 0.8.5 的下游适配：补全 session-ui-adapters 补丁缺失分片、修复 directory-browser `path.posix` 用法与 I18nProvider 导入路径统一，全量同步 resources/pi-web 与 staged 源树（734 文件）。
- 桌面端回归：`test:mobile` 51/0 通过，`test:package` 6/0 通过，`npm test` 211/212（1 个上游环境相关失败，非本次改动引入）。

## 防降级加固

- 修复自动换包在多个 staged 目录并存时可能选中旧版本的问题：现在始终选取最高版本，并在启动路径加入对 staged pi-web 版本的守卫，防止误降到已修复版本之下。

## 模型选择修复

- 修复会话上下文恢复后模型选择器被带偏的问题：SDK 的 `piCtx.model` 记录的是路由器实际解析后的后端模型（如 `aliyun-token-plan/qwen3.7-plus`），会在每轮回复后把选择器从用户显式选择的 `pi-router/auto` 带偏。现从活跃路径上用户最后一次显式 `model_change` 派生选择器显示值；仅在路径没有任何 `model_change`（如全新会话首次切换前）时才回退到 `piCtx.model`。

## 智能路由子项目

继续随主仓库发布 [`packages/model-router-auto`](../../packages/model-router-auto)：面向 Pi Coding Agent 的模型路由与编排扩展。

- 在推理边界按任务阶段、上下文窗口、安全约束、停滞信号和模型黏性选择模型。
- 提供 fail-closed 权限门、日志脱敏、遥测轮转、监督提示和隔离审查沙箱。
- 以 `orchestrator.example.json` 提供匿名配置模板；不随仓库提供任何实际 Provider、模型、认证或使用记录。

## 验证

在生成快照前，完整本地源树执行 memory 治理检查；该检查依赖的本地规划/记忆文件刻意不在公开树中。公开发布树在推送与打 tag 前执行：脱敏快照扫描、独立敏感模式扫描、源代码 whitespace 检查、根项目构建、Pi Web 与移动端回归、桌面打包及一致性检查、智能路由类型检查/测试和隧道测试。打包命令显式使用 `--publish never`，且构建配置设为 `publish: null`；两者共同确保构建过程不会隐式上传构建产物。
