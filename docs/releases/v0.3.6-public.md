# v0.3.6-public

> 本版本在 v0.3.5-public 基础上将内置 Pi Web 运行时升级至 **0.8.6**；从独立的公开发布树构建，运行态、会话数据、遥测、日志、个人配置、基础设施报告和私有运维文档均不包含在公开提交或 Release 中。

## Pi Web 运行时升级（0.8.5 → 0.8.6）

- 内置运行时包升级至 `@agegr/pi-web` **0.8.6**（Pi Coding Agent 保持 **0.83.0**，上游依赖未变）。
- 上游 v0.8.6 主要变更（12 commits）：
  - 持久化显式新会话偏好（new-session preferences）
  - 提示完成（prompt completion）后保留 agent 事件流
  - 修复 API key 保存后的挂起问题
  - 改进插件包安装
  - 降低 agent 消息开销（perf）
  - 技能面板与斜杠面板按休眠状态分组（dormant skills）
  - 扩展对话框播放提示音
  - 改进 iOS PWA 视口与键盘布局
  - 新增 Windows 驱动器选择器
  - Safari 下 DOCX 预览保持同源
  - 关闭时释放 agent 会话（dispose）
- 下游适配（沿用既有 6 项补丁，重建 `session-ui-adapters.patch` 对齐 v0.8.6）：
  - 适配 v0.8.6 新增 `rpcPromptPendingRef` / `model-scope` import / `useI18n` import 的源码变化
  - 保留会话复制/归档 UI、prompt-failure 恢复、压缩后滚动定位、模型加载安全错误包装
  - 将模型选择器派生（用户最后一次显式 `model_change`）与 jiti 测试导入修复并入适配补丁，保证重新 staging 不丢功能
  - staging 脚本新增 `knownTestFailures` 白名单（Windows 8.3 短名 + `~/.agents/skills` 环境碰撞，0.8.5 上同样失败，非回归）
