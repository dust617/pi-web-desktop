# mobile/ — 移动端（安卓互通）子项目

> **所有移动端相关的文件都放在这个文件夹里，避免与桌面端文件混淆。**

## 约定

- 本文件夹是移动端子项目的唯一存放地：规划、连续性文档、以及后续移动端专属代码/资源（如 PWA 静态文件）都放这里或本文件夹下的子目录。
- **不要**把移动端文件散落到 `D:/PI-web-desktop` 根目录。
- 移动端计划**不修改** `resources/pi-web/`（pi-web 锁死版本）。
- 互通桥代码会合并进桌面端 `src/`（用户已确认 C2=合并）；该部分虽在 `src/`，但属于移动端功能，相关说明以本文件夹文档为准。
